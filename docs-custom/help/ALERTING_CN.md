# 告警规则、通知与模板

## 告警规则

告警规则决定什么条件触发告警。新规则上线前应先限制设备组或测试设备，并检查规则查询结果，避免一次产生大量无效告警。

## 通知方式

通知方式负责把已触发告警发送到邮件、Webhook 或其他平台。创建后应使用测试功能验证网络、凭据和接收端返回值。

## 通知模板

模板负责消息内容。优先使用当前模板语法和可用变量，不要继续使用已经废弃的旧模板语法。迁移旧模板时先复制一份，在测试设备告警上验证后再替换生产模板。

## 常见排查

1. 确认告警规则已经启用且命中设备。
2. 确认告警没有处于维护、静默或已确认状态。
3. 检查通知方式测试结果和告警日志。
4. 检查轮询器的 alerting Worker 是否持续运行。
