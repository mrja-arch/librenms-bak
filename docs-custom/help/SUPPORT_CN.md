# LibreNMS 公开故障帮助

本页不包含实验地址、账号、凭据或内部目录信息，可在无法登录时查看。

## 页面无法打开

1. 确认浏览器访问的是管理员提供的 LibreNMS 地址。
2. 检查服务器、反向代理和 LibreNMS 容器是否正在运行。
3. 记录浏览器显示的错误码、发生时间和访问路径。
4. 不要在截图或工单中公开密码、SNMP community、API Token 或私钥。

## 登录失败

确认用户名大小写、浏览器时间和系统时间是否正确。连续失败后不要反复尝试，请由管理员检查认证日志、用户状态和认证后端。

## 文件权限或空白页面

由管理员执行系统配置检验并检查 Web、PHP 和 LibreNMS 日志。请保留完整错误文本，不要只截取最后一行。

## 提交诊断材料

建议提供发生时间、操作步骤、页面 URL、错误码、相关设备名称以及脱敏后的截图。登录后可在运维中心使用诊断收集功能生成诊断包。
