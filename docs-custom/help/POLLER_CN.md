# 轮询器与分布式轮询

## 默认周期

LibreNMS 的常规轮询通常每 5 分钟执行一次，发现通常每 6 小时执行一次；实际周期以当前调度器配置为准。手动触发后仍需等待任务执行和 RRD 文件更新。

## Worker 容量

轮询器页面中的 Worker 秒数接近上限时，应增加 Worker、优化超时或拆分轮询组。盲目增加并发会增加数据库、RRD 和设备 SNMP 压力。

## 分布式轮询

分布式轮询用于负载分担。所有节点必须共享数据库，并按部署方式共享 RRD、日志或缓存。先确保单节点稳定，再逐步加入节点和轮询组。

## 排查

检查 dispatcher 服务、队列积压、poller-wrapper 日志、设备响应时间和数据库连接。设备长期没有 `last_polled` 更新时可在运维中心手动执行设备轮询。
