# 数据库校验与常见故障

## 配置检验

配置检验会检查数据库版本、架构迁移、字符集、排序规则和表结构。修复前先备份数据库，并确认当前容器或代码版本与数据库迁移版本一致。

## 字符集与排序规则

LibreNMS 表和文本列应使用项目当前要求的 `utf8mb4` 排序规则。自定义表必须通过 Laravel Migration 创建，并显式遵循现有数据库默认排序规则，避免配置检验报告异常列。

## 额外表

配置检验把不在官方 schema 中的表标记为额外表。项目自定义功能应同时维护 Migration 和 schema 定义，不能直接在数据库中手工创建后长期不纳入版本管理。

## 修复流程

1. 备份数据库。
2. 记录配置检验的完整输出。
3. 执行待处理 Migration。
4. 运行项目提供的数据库字符集修复命令或经过审核的 SQL。
5. 再次执行配置检验并核对业务页面。
